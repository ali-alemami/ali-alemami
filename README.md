## Featured Projects

* **[philo](https://github.com/ali-alemami/philo)** — Engineered a race-free simulation of Dijkstra's Dining Philosophers using pthreads and mutex locks; built async monitoring routines with microsecond-precision timers preventing thread starvation and deadlocks.
* **[minishell](https://github.com/ali-alemami/minishell)** — Implemented a POSIX-compliant shell with an AST parser enforcing operator precedence, nested subshell forks, and quote-aware tokenization; zero leaks via Valgrind.
* **[pipex](https://github.com/ali-alemami/pipex)** — Engineered a Unix pipeline engine replicating shell redirection (`< file1 cmd1 | cmd2 > file2`) using `fork`, `pipe`, `dup2`, and `execve`; implemented POSIX process synchronization, multi-fd stream redirection, PATH resolution, and child exit status propagation.
* **[push_swap](https://github.com/ali-alemami/push_swap)** — Built a dual-stack radix sort on array stacks with coordinate compression; added lookahead bit inspection in Stack B to cut redundant transfers, with dedicated heuristic solvers for N ≤ 5.
* **[cpps](https://github.com/ali-alemami/cpps)** — Completed 42 C++ Modules 00–09 (OOP, polymorphism, templates, STL); implemented Ford-Johnson Merge-Insert Sort optimizing comparisons via Jacobsthal sequence pairing.
* **[Bank-and-ATM-System-CPP](https://github.com/ali-alemami/Bank-and-ATM-System-CPP)** — Built a terminal-based banking and ATM system in C++ with bitmask user permissions, transaction audit logging, and file-based persistence.
* **[Contacts-App-3Tier](https://github.com/ali-alemami/Contacts-App-3Tier)** — Built a 3-tier application structure in C# demonstrating data access separation with ADO.NET and parameterized T-SQL queries.
* **[webserv](https://github.com/ali-alemami/webserv)** *(In Progress)* — Non-blocking HTTP/1.1 server using socket polling and I/O multiplexing, with request parsing and CGI execution.
* **[inception](https://github.com/ali-alemami/inception)** *(In Progress)* — Multi-container infrastructure with Docker Compose; isolated containers for NGINX (TLS/SSL), WordPress, and MariaDB with bind mounts and internal bridge networking.
